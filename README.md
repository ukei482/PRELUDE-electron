# PRELUDE (Electron版)

ブラウザ・エクスプローラ・ウィンドウ管理を1つにまとめた自分用ツール。
Rust + GPUI 版（`../PRELUDE`）の考え方を、Chromium（Electron）で作り直したものです。
Windows / Linux のどちらでも同じコードで動きます。

## 起動
```
npm install
npm start            # Windows
npm run start:linux  # Linux（サンドボックスで起動できない環境向けに --no-sandbox 付き）
```
必要なもの：Node.js 20 以上。

## できること
- **自前のタイトルバー**（最小化・最大化・全画面・閉じる、ドラッグで移動）
- **縦タブ** + **ブックマーク**（Web / フォルダ。1ブックマーク = 最大1タブ。右クリックで名前変更・削除）
- **分割ペイン**：左右 / 上下に何段でも分割、境界線をドラッグしてサイズ変更。ペインの種類は Web / フォルダ / 設定
- **Webペイン**：URL・検索ワード入力（日本語IME対応）、戻る・進む・再読込、アドレス欄はページ遷移に追従
  - `target=_blank` のリンクは分割ペインで開く
  - ポップアップ（ログイン用の `window.open`）は本物のウィンドウで開く（OAuthの opener を保つため）
  - UAは通常のChromeと同じ（`Electron/` を含めない）
- **ダウンロード**：保存先を選ぶフォルダペインが開く（「ここに保存」/ キャンセル）
- **アプリ取り込み（KDE Plasma 6 / Wayland のみ）**：ペイン種類「アプリ」から、インストール済みアプリ（.desktop）または任意のコマンドを起動し、そのウィンドウをペインの位置に枠なし・最前面で重ねて配置。分割・タブ切替・ウィンドウ移動に追従し、ペインを閉じるとアプリも終了。次回起動時に再起動して復元：ダブルクリックで移動 / 既定アプリで開く、上へ・ホーム・ドライブ一覧、パス入力、仮想スクロール
- **設定タブ**：`config.js` の `SCHEMA` から自動生成（色・文字サイズ・ホームページ・検索エンジン・ショートカット…）
- **タブの復元**：終了時のタブ・分割配置を次回起動で復元
- ショートカット：Ctrl+T / Ctrl+W / F11（設定で変更可）、Ctrl+L（アドレス欄）、F5 / Ctrl+R（再読込）、Alt+←/→（戻る/進む）、Ctrl+±/0（ズーム）、F12（DevTools）。Webページにフォーカスがあっても効きます

設定と履歴の保存先：`%APPDATA%\PRELUDE-electron\`（Linuxは `~/.config/PRELUDE-electron/`）。
初回起動時に Rust 版の `%APPDATA%\PRELUDE\config.json` があれば、色・ブックマークなどを引き継ぎます。

## まだ入っていないもの
- **アプリ取り込みの制限**：実際には「重ねて配置」なので、他のウィンドウがPRELUDEの上に来ても取り込み中のアプリは最前面のまま。KDE以外（GNOME拡張など）は未対応。Flatpak等でPIDが一致しないアプリはウィンドウクラス(StartupWMClass)で照合します。
- ブラウザ拡張機能（Chrome拡張）、パスワードマネージャ連携、Webビューの右クリックメニュー。
- Webの上にHTMLのポップアップは重ねられません（Webビューはネイティブ描画のため）。メニュー表示中・境界ドラッグ中はWebビューを一時的に隠しています。

## 構成
- `main.js` … ウィンドウ、Webビュー(WebContentsView)の管理、ダウンロード、ファイル操作、ショートカット
- `preload.js` … 画面側に公開する安全なAPI（`window.preludeApi`）
- `appembed.js` … アプリ取り込み（プロセス起動とKWinスクリプトによるウィンドウ配置）
- `config.js` … 設定の初期値と設定画面のスキーマ
- `src/index.html` / `style.css` / `app.js` … 画面（縦タブ・分割ツリー・各ペイン）
- `assets/icons/` … アイコン（Rust版と同じSVG）

## 実装メモ
- Webページは画面側の `.web-slot`（空の箱）の位置・大きさを `main.js` へ送り、その上に `WebContentsView` を重ねています。
- 動作確認は Linux（Xvfb）上で、タブ・分割・ダウンロード・ブックマーク・設定の自動テスト28項目を通しています。
